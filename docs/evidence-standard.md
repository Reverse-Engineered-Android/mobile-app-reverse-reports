# 证据标准

## 函数证据

每个关键结论应至少给出：

1. 文件名与文件内/虚拟地址。
2. 导出符号或 stripped 函数起点。
3. 3-15 行足以证明 ABI、常量、调用目标或 SQL 语义的代码片段。
4. 对寄存器、参数和返回值的解释。
5. 已验证、结构已证实或假说的等级。

## 数据库证据

- 使用实际表名和 `PRAGMA table_info` 得到的列名。
- DDL 只有在字符串或 `sqlite_master` 中可靠恢复时才称为 exact。
- 个人数据只允许聚合数量、类别和时间范围，不提供行样例。

## 算法证据

- 对外层字节布局提供可重放公式或代码。
- 对未复原的内部压缩函数、会话生成器或 blob 解密明确标记未知。
- 测试向量必须是合成 build/device/token，不能使用真实用户材料。
