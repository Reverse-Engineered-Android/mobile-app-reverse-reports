# 高德数据内容概要

本页只包含聚合信息。

## `bedstone.db`

- `fLocationInfo`：25 行。
- 类别：定位/兴趣点缓存。
- 字段类别：POI、地点名、内部坐标、时间、交通类型、扩展 JSON。

## `girf_sync.db`

| 类别 | 数量 | 字段主题 |
| --- | ---: | --- |
| 路线历史 | 187 | 起终点、途经点、路线类型、交通方式、状态、时间 |
| 搜索历史 | 73 | 搜索结果、POI、地址、行政区、坐标、时间 |
| 用户同步对象 | 284 | 类型、对象 ID、JSON payload、事件时间 |
| 设置 | 18 | 设置项和版本 |
| 系统配置 | 5 | 内部配置 |
| 本地对象 | 15 | 本地设置和缓存 |

- 时间跨度：约 2024-04-18 至 2026-09-26。
- 可识别行为：重复路线、搜索到路线的转化、常用 POI、设置变化和删除/陈旧状态。

真实城市、地点、路线、搜索词、地址、坐标和时间线均未公开。
