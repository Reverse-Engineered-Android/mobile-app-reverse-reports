# 纷玩岛 3.42.0

研究对象是官方版本 `3.42.0`（versionCode `362`）、包名 `cn.com.livelab` 的 ARM64
APK、随包分发的 native 库、Flutter/Dart 快照、资源与服务端接口定义。搜索、活动、
购票、查看票夹等业务链路全部采用**静态只读**调查：未登录、未构造或发送任何请求、
未下单、未支付、未实际上传或下载业务文件、未绕过风控。另对自有 Android 设备做
**只读**运行态核对：只读取应用私有数据目录中的数据库 schema 与已落盘文件，未写入
设备、未发起网络请求。

样本 SHA-256：
`b00ea747c55ad39b4075745577e97d8d0ce6cc1f068a9bf4b11dc68eb7c9063e`，
大小 `84,046,532` 字节，APK 条目 `2,316` 个，ARM64 native 库 `18` 个。

## 覆盖范围

- 240 条业务路径的 HTTP 出口、公共拦截器、请求头与响应封装格式。
- 认证链路：手机号 / 短信 / 微信 / 华为 / Apple / 身份认证，令牌与刷新机制。
- 搜索、活动、购票、票夹、发票、支付预下单的静态接口与字段族。
- 上传与下载的具体数据范围（七牛上传、私有 PDF、发票 URL、静态资源）。
- 风控全链路：Geetest 四代验证码参数拼装、设备指纹、请求签名与响应错误分支。
- `libgtc4core.so` 的 `.datadiv_decode*` 混淆：**逐字节算法还原**，不保留未知实现。
- `SharedPreferences` 落盘密文的**流密码结构还原**与密钥流复用判定。
- 权限声明、导出组件、隐私同意链、越权 / 提权 / 未经告知 / 超范围判断。
- 只读设备端数据库 schema 与共享配置落盘格式核对。

## 研究边界

客户端静态分析能证明“代码采集什么、在何条件触发、写入哪个字段、调用哪个端点”，
不能证明服务端保存多久、如何评分或采取何种处罚。报告把客户端事实、跨版本可比事实
和服务端不可见部分严格分开；不提供登录绕过、签名伪造、下单攻击或批量抓取方法。
`libDexHelper.so` / `libdexjni.so` 的 DEX 装载壳只描述其装载边界与可验证特征，
不臆测未被静态证据支持的算法内部。
