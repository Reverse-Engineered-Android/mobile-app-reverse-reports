# 小米应用商店（com.xiaomi.market）

本目录记录对小米应用商店 Android 客户端的静态与只读设备证据研究，重点回答三个隐私/风控问题：

1. 客户端是否会采集并上传本机应用列表；
2. 风险应用检测如何触发、由谁判定；
3. 检测到风险或“非法”应用后，是否会单独把检测结果回传服务端。

结论摘要见 [report.md](report.md)。分析以 APK 静态反编译、公开端点与常量、本地持久化结构和只读设备快照为准；不包含对服务端内部逻辑、留存或处罚策略的证明，也不提供绕过检测、伪造签名或规避风控的方法。

## 研究边界

客户端事实只能证明“采集什么、何时触发、写入哪个字段、发往哪个端点”。服务端如何计算风险、是否保留历史、是否对用户或设备采取动作不可由客户端代码证明。报告中的“未发现”均指静态代码与可检查的本地数据中未见，不等价于服务端没有相应能力。
