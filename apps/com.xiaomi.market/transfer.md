# 上传与下载范围

## 会离开设备的应用数据

| 场景 | 字段/对象 | 说明 |
|---|---|---|
| 每日安全扫描 V1 | 非系统可卸载 app 包名列表 | 逗号拼接 |
| 每日安全扫描 V2 | `packageName`、`versionCode`、`signatureMD5` | 签名证书 MD5 |
| 更新检查 | 包名、版本、`oldApkHash`、是否商店安装、APK 来源、split 列表 | 批量 |
| 差分更新 | 包名、`oldApkHash` | `updateinfo/diffsize` |
| 桌面推荐/分类 | 相关本机应用状态 | 批量 |
| 装包校验 | 包名、版本、签名哈希、显示名、installer、时间戳、nonce | 覆盖外部安装/商店安装校验 |
| 活跃统计 | 包名、版本、安装器、渠道、活跃时间/类型、APK 哈希、安装/更新时间、安装来源、traceId、userId | 每应用 |
| OneTrack 行为 | 曝光、点击、下载、安装、打开、卸载、升级等事件 | 行为对象含包名/应用 ID |
| AI 推荐 | installed、uninstalled、upgraded、opened 行为列表；3/7/14/30 天 UsageStats | 请求对象字段完整 |
| 风险通知特征 | 风险应用数量、保留应用数量、占比等级、风险应用 3/1 天使用时长 | 不含逐个风险包名 |
| 安全扫描埋点 | 是否自动、V1/V2、相关实验开关 | 全量采样 |
| 验证 SDK 环境 | 设备环境、hook/虚拟化/模拟器/root 状态、传感器值 | 验证码/风控场景 |

## 不会单独上传的本地数据

| 数据 | 本地作用 |
|---|---|
| 风险忽略集合 | 只写入 `security_check_risk_app_ignore_pref`，用于过滤展示 |
| `app_security_data` | 服务端返回缓存，供评分/展示 |
| `h_b` 行为表 | 供 AI 推荐构造请求；请求时会序列化为行为对象上传 |
| `app_usage` / 本机应用缓存 | 本地缓存；部分内容会被后续请求间接使用 |
| MMKV 历史时间戳 | 判断扫描频率与调度 |

## 服务端下发

| 数据 | 作用 |
|---|---|
| `judgingRules(V2)` | 客户端评分阈值 |
| `riskAppList` | 风险包名、等级、类型、展示文案 |
| `appSecurityText` | 标题、详情、忽略提示 |
| `checkDuration` | 扫描间隔 |
| 风险通知模型 | XGBoost 模型文件与配置 |
| AB 实验 | 启用 V2、自动扫描、通知模型等 |

## 结论

上传面以“完整本机应用清单”为中心：安全扫描是最直接的一类；更新、推荐、装包校验、活跃统计和 AI 请求覆盖更丰富的安装/使用行为。检测出的风险结果本身没有发现专用回传端点，但行为遥测和每日清单使服务端具备关联能力。
