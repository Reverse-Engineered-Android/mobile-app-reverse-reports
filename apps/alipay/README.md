# Alipay Android 静态逆向报告

本目录分析支付宝 Android `12.12.30.8000`（versionCode `212310`）的本地数据库、登录/支付调用面和设备风控采集面。分析限定为离线静态证据，不执行登录、支付、真实网络请求或服务端交互。

- [主报告](report.md)：数据库覆盖、登录/在线支付/离线支付路径、认证与风险采集。
- [逐库清单](database-inventory.md)：61 个数据库的格式、解密状态、对象与聚合数量。
- [证据索引](evidence.md)：DEX/ELF/数据库源位置和可复核检查。
- [Schema 摘要](schema.md)：已恢复的表/列和敏感字段边界。
- [设备风险](device-risk.md)：仅列字段族、类型和聚合数量。

## 结论摘要

- 61 个 `.db` 文件全部纳入清单：36 个普通 SQLite、7 个已恢复的 SQLCrypto 数据库、13 个密码/保护域未从静态证据恢复的 SQLCrypto 数据库、5 个 UnQLite 键值库。
- SQLCrypto 页面编解码在 ELF 中是逐 16 字节 AES 块处理；本次仅公开算法结构，不公开密码、恢复步骤或解密输出。
- 登录密码进入 `RSAEncrypt` 后由服务端校验；授权登录使用 `authCode` 换取 `userToken`，会话按 appId/domain/sessionId 分域保存。
- 在线调用使用 MTOP 的 `apiName`、`version`、JSON `data`，GET 查询串或 POST 表单体；请求头暴露登录、设备、签名、时间和风控相关字段名，但签名生成方法未完整恢复。
- 离线支付由二维码/OTP/NFC 多层组成：二维码版本化校验、防重复与时间戳检查；OTP 初始化携带设备身份和 OS 信息，续期携带 seed 摘要、索引和算法。
- 风控证据显示指纹硬件状态、认证器启动、快速支付授权和设备/传感器元数据被采集；公开内容只保留字段名、类型和聚合数量。

## 使用边界

报告不包含数据库、APK/DEX/SO、密钥、token、账号、设备标识、真实请求/响应、坐标或绕过认证/风控的方法。算法描述用于防御审计、数据可移植性和取证复核。
